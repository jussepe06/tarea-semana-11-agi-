xtracción de Requerimientos del Laboratorio (K-Means Clustering)[Seguro] La actividad exige segmentar un conjunto de datos sin etiquetas (1 de 12 casos posibles) generado a partir de tu código de alumno de la USIL. El entregable debe cumplir con los siguientes hitos:   Datos: Generar el dataset, mostrar estadísticos y definir las variables.   Visualización Previa: Scatter plot inicial y predicción manual de K.   Optimización de K: Estandarizar variables, calcular Inercia (codo) y Silueta, y justificar cuantitativamente la elección de K.   Entrenamiento: Entrenar K-Means con parámetros estrictos (init="k-means++", n_init=10, random_state=42), calcular perfiles, graficar barras y nombrar estratégicamente cada segmento.   Estrategia y Ética: Definir un producto/servicio, canal y métrica por grupo, además de identificar un riesgo ético crítico.   Escenarios 'What if': Medir impacto al forzar $K=2$ y $K=10$, omitir la estandarización (midiendo con adjusted_rand_score), alterar semillas (random_state) y añadir variables de ruido.   Razonamiento: Asignación por distancia a centroides, limitaciones del algoritmo y justificación ante gerencia.   Integridad: Código de verificación y Anexo de prompts utilizados.
